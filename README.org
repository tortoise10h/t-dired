This is a terminal file manager written in Go which is heavity inspired by Emacs Dired (TBH, my goal is to port the full Emacs Dired experience into a TUI application). Since I'm an Emacs user, I'm familiar with Dired UI, keybindings and the philosophy. But I don't live in Emacs all day (I know, that goes against the "Emacs philosophy" right). So when I'm in the terminal and want to quickly check files, I'd love to have Dired here as well. That's why I'm build ~t-dired~ for.
